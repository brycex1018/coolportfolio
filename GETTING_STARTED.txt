================================================================================
  🚀 QUICK START (5 Minutes)
================================================================================

Step 1: Install Python 3.8+ (if not already installed)
   → Download from: https://www.python.org/downloads/

Step 2: Install dependencies
   $ cd screen-clipper
   $ pip install -r requirements.txt

Step 3: Run the application
   $ python main.py

Step 4: Use it!
   • Recording starts automatically
   • Press F9 to save the last 5 minutes
   • Press F8 to pause/resume
   • Press ESC to exit
   • Find clips in the clips/ folder

That's it! You now have a working screen clipper! 🎉

================================================================================
  🎛️ CUSTOMIZATION
================================================================================

Edit screen-clipper/config.toml to change:

• Buffer duration (5 min default, up to 24 hours)
• FPS (30 default, 5-60 range)
• Resolution (1.0x default, 0.5-1.0 range)
• Hotkeys (F9 save, F8 pause, ESC exit)
• Output directory
• Video codec
• And much more!
